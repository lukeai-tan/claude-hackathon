OpenSuite 0.3.0 combines OpenPDF and OpenSlides in one Windows download.

- Shared home to open both bundled editors, with standalone downloads available.
- OpenPDF workspace refresh: purple navigation rail, focused tool panels, page thumbnails, fit-to-page and correct saved-document status.
- OpenSlides with Ask Claudia, templates, themes, 19 bundled fonts, standard elements, generated SVG elements and an AI agent builder.
- Source organized under source-code/main, source-code/OpenPDF and source-code/OpenSlides.
- Local editing and storage; Claudia needs your own API key and internet access.

Choose OpenSuite-Setup for an installer or OpenSuite-Portable to run without installation. These Windows x64 hackathon executables are unsigned. SHA256SUMS.txt contains download checksums. Source and license notices are included in the repository/source archives. OpenPDF's OCR runtime is bundled; Office-to-PDF import additionally requires LibreOffice.
