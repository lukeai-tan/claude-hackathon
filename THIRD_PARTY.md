# OpenSuite licenses

OpenSuite combines independently maintained components. Corresponding source and build scripts are published in this repository and attached to each GitHub release through its source archives.

- The OpenSuite launcher and OpenPDF are licensed under AGPL-3.0-or-later. See `LICENSE` and `source-code/OpenPDF/LICENSE`.
- OpenSlides retains its MIT license: `source-code/OpenSlides/LICENSE`.
- OpenPDF's PyMuPDF, Tesseract, Pillow, pdf2docx and other dependency notices are retained in `source-code/OpenPDF/THIRD_PARTY.md`.
- OpenSlides' embedded typeface license notices are in `source-code/OpenSlides/public/fonts/LICENSES/` and its font manifest.
- Electron and the JavaScript dependencies retain their respective licenses. Electron license files are included by electron-builder in the Windows distribution.

No Canva assets or branding are included. The interface takes inspiration from the supplied reference layouts.
