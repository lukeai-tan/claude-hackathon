# OpenSuite build 12 — PDF update

This release retains the integrated OpenSuite design and includes the existing OpenSlides editor unchanged.

PDF improvements:

- Horizontal trackpad scrolling and proportional vertical scrolling using Windows preferences; Ctrl+wheel still zooms.
- Text highlighting mode and translucent freehand highlighting, with thickness adjustment and undo/redo.
- Configurable watermarks, including 45-degree full-page and repeated layouts, colour, opacity and page scope.
- Click Edit text boxes again to exit editing mode and hide the outlines.
- PDF navigation, long action labels, category scrolling and formatting toolbars adapt to smaller windows.

Windows builds include English OCR. The workflow tests the PDF engine, desktop controls, compact PDF layouts, and the packaged suite before publishing. Executables are unsigned.
