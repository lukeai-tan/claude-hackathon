# Additional bundled fonts

Latin and Latin Extended-A subsets of DejaVu (Bitstream Vera licence; DejaVu changes are public domain) and Latin Modern (GUST Font License / LPPL 1.3c). Original glyph designs and font metadata are retained; FontTools re-encodes the subsets as WOFF embedded in `src/styles/extra-fonts.css`. Upstream authors, terms and source information are in LICENSES.

- DejaVu Sans (400): DejaVuSans.ttf
- DejaVu Sans (700): DejaVuSans-Bold.ttf
- DejaVu Serif (400): DejaVuSerif.ttf
- DejaVu Serif (700): DejaVuSerif-Bold.ttf
- DejaVu Sans Mono (400): DejaVuSansMono.ttf
- DejaVu Sans Mono (700): DejaVuSansMono-Bold.ttf
- Latin Modern Roman Caps (400): lmromancaps10-regular.otf
- Latin Modern Roman Dunhill (400): lmromandunh10-regular.otf
- Latin Modern Mono Caps (400): lmmonocaps10-regular.otf
- Latin Modern Sans Demi Cond (400): lmsansdemicond10-regular.otf
